# 09 Component Responsive Audit

1. **HomeHero**: Mobile-first single column, left-aligned, stacked buttons.
2. **Countdown**: `grid-template-columns: repeat(4, minmax(0, 1fr))` with `tabular-nums`.
3. **HeroSlider**: Isolated horizontal scrolling container with touch momentum.
4. **HelplineDirectory**: Collapses to single column on mobile with full-width call buttons.
5. **FeatureGrid**: Category filter chips wrap cleanly; cards stack 1-column on mobile, 2-column on tablet, 3-column on desktop.
