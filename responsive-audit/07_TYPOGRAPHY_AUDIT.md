# 07 Typography Responsiveness Audit

- **Hero Heading (`h1`)**: Uses `font-size: clamp(22px, 5.5vw, 40px)`. Line-height: 1.12. Word wrapping: `overflow-wrap: break-word`.
- **Section Headings (`h2`)**: Uses `font-size: clamp(20px, 3.5vw, 26px)`.
- **Subheadings (`h3`)**: Uses `font-size: clamp(16px, 2.5vw, 20px)`.
- **Body Text**: Uses `font-size: 14px` (`--t-base`), line-height: 1.6.
- **Form Inputs**: Set to `16px` font size on mobile viewports to prevent iOS Safari input focus auto-zooming.
