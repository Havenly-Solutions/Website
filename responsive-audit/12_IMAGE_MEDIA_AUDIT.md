# 12 Image & Media Audit

- **Next.js Image Component**: Uses `<Image />` with `fill`, `sizes`, and `priority` attributes.
- **Global Image Rule**: `img, svg { max-width: 100%; height: auto; }`.
- **Mascot Graphic (`jabu.png`)**: Scaled responsively with `height: min(280px, 45vw)` on tablet and hidden on mobile ($\\le 640\\text{px}$).
